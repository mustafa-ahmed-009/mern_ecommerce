# 🛍️ E-Commerce Platform (MERN Stack)

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://mern-frontend-inky.vercel.app)

![Tech Stack](https://img.shields.io/badge/stack-MERN-61DAFB?logo=react&logoColor=white)

A full-featured e-commerce platform with admin dashboard, built with React 19, Node.js, Express, and MongoDB.

## 🌟 Features

### 🛒 Shopping Experience
- Product browsing with filters (category, price, ratings)
- Shopping cart with persistent storage
- Secure checkout process
- Order history tracking

### 👨‍💻 Admin Dashboard
- Product & category management (CRUD)
- Order processing system
- User management

### 🔒 Security
- JWT authentication with email verification
- Password encryption
- Role-based access control

## 🛠️ Tech Stack

**Frontend:**
- React 19 (Vite)
- TypeScript
- Redux Toolkit (state management)
- Tailwind CSS + DaisyUI
- React Hook Form

**Backend:**
- Node.js + Express
- MongoDB (Mongoose)
- JWT Authentication
- Cloudinary (image uploads)
- Nodemailer (email verification)
